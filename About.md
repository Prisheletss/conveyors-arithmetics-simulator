## Суть программы

Имеется рабочая область, в которой можно размещать квадраты разных цветов. Цвет квадрата можно выбрать в верхней панели. Также, есть кнопка "курсор", при нажатии на которую -- можно перемещать и удалять квадраты; также доступен режим массового выбора, и соответствующих функций для группы квадратов.


## Файлы

`index.html` &mdash; файл для инициализации окна в проводнике

`styles.css` &mdash; описание спрайтов, их расположение

`scrypt.js` &mdash; рабочая программа, разбита на 3 группы:
+ Инициализация переменных
+ Функции
+ Ивенты
