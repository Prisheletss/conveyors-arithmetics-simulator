<h1 align="center">conveyors-arithmetics-simulator</h1>

Бесплатный сайт с 2д квестами по распределению ресурсов на конвейерах. Вдохновлён играми по типу Factorio, Satisfactory, Shapez, Infinifactory и др

## 🎯 Цель проекта
Написать сайт с конструктором конвейерных схем для решения задач по арифметике и алгебре в рамках развлекательной математики в образовательных учреждениях

<br>

Пример задачи: отделите 1рес/мин от конвейера в 5рес/мин при помощи: соединитель на 2/3, разъединитель на 2/3

Возможное решение:

![example1](https://github.com/Prisheletss/Satisfactory-calculator-unofficial-/blob/main/%D1%80%D0%B8%D1%81%D0%BE%D0%B2%D0%B0%D1%88%D0%BA%D0%B0/%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/(1%20%D0%BA%205)%20%D0%B8%20(4%20%D0%BA%205).png)

<br>

Ещё возможные задачи:
+ сделайте так, чтобы хотябы по одному конвейеру ехало ровно 7рес/мин для **любых** входных значений в интервале 1-10 при помощи: соединитель на 2/3, разъединитель на 2/3. Учтите, что максимальная пропускная способность ленты &mdash; 10рес/мин
+ На входе 3 конвейера: белый, синий, красный. На каждом из них едет 1рес/сек. Требуется вывести две конвейерные ленты: на одной из них флаг России, а на втором &mdash; Франции. Доступные инструменты: соединитель на 2, разъединитель на 2

<br>

Можно добавить возможность создания учебных групп. В каждой группе учитель сможет смотреть статистику решения задач. Так же можно добавить инструментарий для автоматической проверки эффективности решения по следующим параметрам:
+ занимаемая площадь
+ число узлов в сети
+ общность схемы (масштабируемость под другие вводные)
+ скорость запуска
+ ...
